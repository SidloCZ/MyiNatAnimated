MyiNatAnimated

Aplikace vyžaduje spuštění na webovém serveru (lokálně přes npm run dev nebo na hostingu). Moderní webové prohlížeče z bezpečnostních důvodů (CORS) blokují načítání ES modulů přímo přes protokol file://.

# Spuštění vývojového serveru:
npm run dev
# Nebo produkční náhled:
npm run preview
